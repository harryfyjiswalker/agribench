# Datasets and Evaluation Protocols



## Crop Type Classification

### Datasets

- _In-domain performance_: [PASTIS-R](https://zenodo.org/records/5745151) (Garnot and Landrieu, 2021) is a benchmark that supports parcel-based crop type classification, comprising 124,422 individual parcels and 18 crop types in metropolitan France. The benchmark covers one year, the September 2018 to November 2019 growing season.
- _Leave-One-Region-Out_: [PLANTEUR](https://github.com/allenai/planteur-benchmark) (Wolters _et al._, 2026) is a complementary benchmark comprising the same content but for eight of France's overseas territories, enabling analysis of smallholder and tropical crop type mapping performance and supporting analysis of geographic generalisation.
